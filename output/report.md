# UCI Online Retail II 电商经营分析报告

> 数据集：UCI Machine Learning Repository — Online Retail II（英国在线礼品零售商公开数据，
> 覆盖 2009-12-01 ~ 2011-12-09，有效订单行 779,407）。
> 全部结论由 analysis.sql 中的 SQL 在 SQLite 实际跑出，可复现；数据为公开数据集，非真实业务数据。

## 一、经营大盘

- 有效 GMV **£17,374,804**，购买客户 **5,878** 人，订单 **36,969** 单，商品 SKU **4,630** 个
- 月度 GMV 峰值出现在 **2010-11**（£1.17M，订单 2,587 单）
- 英国本土贡献 GMV 占比 **82.8%**，其余为欧洲/澳洲等海外市场
- 三层分解恒等式成立：月度净 GMV = 活跃客户数 × 人均订单数 × 客单价（可作为日常监控指标体系底座）

## 二、监控口径：环比 vs 同比

- GMV 存在强季节性（年末礼品旺季），**环比会被季节性污染**，异动监测应改用同比
- 末月（2011-12）仅 1–9 日数据，截断造成的「环比大跌」为假异动，监控时需剔除
- 重点月份 2011-04：GMV 同比 **-20.9%**、环比 -21.2%——同比口径下才是真实经营异动

## 三、异动归因：新客端 vs 老客端

- 2011-04 新客：客户 106、GMV £41K、人均 £388
- 2011-04 老客：客户 750、GMV £427K、人均 £570
- 结论口径：拆到新客/老客两端，定位同比下滑的主要来源（新客端 vs 老客端贡献对比）

## 五、复购与留存

- 购买客户 **5,878.0** 人，订单 **36,969.0** 单（首单 5,878.0 / 复购 31,091.0）
- 客户口径复购率（购买 ≥2 单客户占比）**72.4%**，人均订单数 **6.29** 单，单用户最多 **398.0** 单
- 月复购率基线（当月活跃且上月也活跃）均值 **38.84%**；按此基线测算，检出 +10% 相对提升所需每组样本约 **2,513** 人

## 六、统计检验（订单金额差异）

- 对比 2011-04（n=22,432，均值 £20.88）vs 其他月份（n=756,975，均值 £22.33）的订单金额
- 对数变换后 Welch t 检验：t=0.692，p=0.4888
- Mann-Whitney U 检验：U=8586937949.0，p=0.003587
- **Cohen's d = 0.005** —— 统计显著但业务效应微弱，据此判断：不建议针对该差异投入资源

## 八、方法说明

- 数据治理：剔除取消单（Invoice 以 C 开头或 Quantity<0 双条件）、无客户 ID 行、重复行
- RFM：NTILE(5) 窗口函数五分位打分，R 按距基准日（2011-12-10）近远反向计分
- 复购：ROW_NUMBER() 按用户分区标记首单/复购；月复购率用上月活跃对齐
- 三层分解：活跃客户数 × 人均订单数 × 客单价，恒等式校验通过
- 同比：LAG(gmv, 12) 窗口偏移；末月截断需在监控中显式剔除
- 统计检验：对数变换 + Welch t + Mann-Whitney U + Cohen's d（scipy）
